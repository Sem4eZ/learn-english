# Fluentiq — English Mastery Platform 🚀

**Fluentiq** — современная полнофункциональная платформа для интерактивного изучения английского языка. Построена на базе **React + TypeScript (Feature-Sliced Design)**, компонентной системы **Ant Design**, стилизации на **SCSS Modules** и высокопроизводительного бэкенда на **Node.js** с нативным **SQLite WAL**.

---

## 🌟 Возможности платформы

### 🎮 6 интерактивных тренажёров
1. **📘 Грамматика и контекст**:
   * Задания на подстановку пропущенных слов, предлогов и временных форм.
   * Ситуационный контекст, моментальный разбор правил и объяснение правильного ответа.
   * Выбор тематических направлений (*IT, Бизнес, Разговорный, Путешествия, IELTS/TOEFL, Грамматика*) и уровней сложности (A1–C1).
2. **🎯 Квиз 1 из 4**:
   * Быстрое тестирование словарного запаса с вариантами ответов и разбором.
3. **⚡ Скоростной Спринт (60 секунд)**:
   * Динамичная тренировка реакции и правильности перевода с комбо-множителями очков (x2, x3, x4).
4. **🧩 Конструктор слов (Спеллинг)**:
   * Сборка слов по буквам для оттачивания безошибочного правописания.
5. **🗂️ 3D Флеш-карточки с интервальным повторением (SM-2)**:
   * Алгоритм SuperMemo-2 (SM-2) с 4 кнопками интервалов: `[1] Снова`, `[2] Трудно`, `[3] Хорошо`, `[4] Легко`.
   * Поддержка горячих клавиш (`Пробел`, `1`, `2`, `3`, `4`), озвучка произношения (TTS), примеры и транскрипция.
6. **🎧 Аудирование и диктант**:
   * Восприятие английской речи на слух с нормальной (1.0x) и замедленной (0.75x) скоростью, интерактивная сборка фразы.

### 📖 Интерактивный словарь
* Быстрый поиск по английским словам, русскому переводу или определениям.
* Фильтры по уровням CEFR (A2–C1), избранному и темам.
* Ленивое автоматическое обогащение базы новыми словами и кнопка мгновенного пополнения.

---

### 🏆 Геймификация, аналитика и профили
* **Система уровней и опыта (XP)** за каждый правильный ответ и пройденный урок.
* **Серия занятий (Daily Streak)** для выработки ежедневной привычки.
* **История ответов и работа над ошибками**: полный журнал ответов с возможностью отфильтровать только ошибки и разобрать правила.
* **Легковесная авторизация**: вход и регистрация без лишних подтверждений.
* **Смена темы оформления**: тёмная и светлая темы с плавной адаптацией.

## 🛠️ Стек технологий

* **Frontend**:
  * React 19, TypeScript
  * Архитектура **Feature-Sliced Design (FSD)**
  * Стилизация: **SCSS Modules** с едиными дизайн-токенами
  * UI-библиотека: **Ant Design** (antd) + Ant Design Icons
  * Сборка: **Vite**
* **Backend**:
  * **Node.js 22** + Express
  * База данных: встроенный нативный **SQLite (`node:sqlite`)** в режиме **WAL (Write-Ahead Logging)**
  * REST API + Spaced Repetition Engine

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd english
```

### 2. Установка зависимостей
```bash
# Установка зависимостей сервера
cd server
npm install

# Установка зависимостей клиента
cd ../client
npm install
```

### 3. Настройка переменных окружения
Скопируйте пример конфигурации в папке `server`:
```bash
cd ../server
cp .env.example .env
```
При необходимости укажите ваши ключи в файле `server/.env`.

### 4. Запуск приложения

#### Вариант A: Через `start.bat` (Windows)
Просто запустите файл `start.bat` двойным кликом.

#### Вариант B: Через единый раннер
```bash
# Из корневой директории:
node run.js
```

#### Вариант C: Раздельный запуск в двух терминалах
```bash
# Терминал 1 (Бэкенд - порт 3001)
cd server
npm start

# Терминал 2 (Фронтенд - порт 3000)
cd client
npm run dev
```

Приложение доступно по адресу: **http://localhost:3000**  
API бэкенда работает на: **http://localhost:3001**
